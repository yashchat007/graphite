# Graphite

A glassmorphism task dashboard for capturing work, staying in focus, and syncing across devices.

## Built with

React, Vite, TypeScript, Tailwind CSS, Framer Motion, Zustand, Vercel serverless functions, Upstash Redis, Vercel Blob, and an installable PWA.

## Features

- Tasks with stars, completion, drag-and-drop reorder, due dates, and NLP quick-add
- Smart lists: Inbox, Today, Upcoming, Starred, and Completed
- Focus stopwatch tied to the task you are working on
- My files: private uploads with 7-day expiry and pin-to-keep
- Cross-device sync secured with a shared access key
- Installable PWA with offline-friendly local state
